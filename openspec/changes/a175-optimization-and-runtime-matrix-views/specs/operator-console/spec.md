## ADDED Requirements

### Requirement: 최적화 화면의 내비게이션은 하나다

최적화 화면의 카테고리 이동 수단은 왼쪽 카테고리 메뉴 하나여야 한다(SHALL). 개요 카테고리의 카드 그리드처럼 같은 목적지를 반복하는 두 번째 목록은 두지 않는다(SHALL NOT). 운영 권한 요약(KPI) 묶음은 개요 카테고리에서만 렌더된다(SHALL). 다른 화면으로 넘기기만 하는 카테고리는 요약 한 줄과 링크만 가지며 대상 화면의 값을 재계산하지 않는다(SHALL NOT). 카테고리 deep link 와 제출 경로는 바뀌지 않는다(SHALL NOT).

#### Scenario: 중계 카테고리
- **WHEN** 종목별 관리 카테고리를 열면
- **THEN** 대상 화면의 요약 한 줄과 링크가 있고 KPI 묶음과 카드 그리드는 없다

### Requirement: 반복 구조는 행렬로 비교된다

같은 구조가 시장(KR/US)이나 프리셋마다 반복되는 표시는 행렬 하나로 렌더해야 한다(SHALL): 익절 프리셋은 단계×프리셋, 후보 필터는 사유 코드×시장, strategy runtime 은 필드×시장. 공통 설명과 공통 행은 1회만 나타난다(SHALL). 행렬은 1280px 과 390px 폭에서 잘리지 않아야 한다(SHALL). 접기는 설명에만 쓰고 수치·사유·안전 상태는 접지 않는다(SHALL NOT).

#### Scenario: 익절 프리셋 비교
- **WHEN** 익절·보호 카테고리를 열면
- **THEN** 세 프리셋의 단계별 값이 한 표의 이웃 열에 있고 프리셋마다 선택 폼이 하나다

#### Scenario: 좁은 화면의 후보 필터
- **WHEN** 390px 폭에서 후보 필터 카테고리를 열면
- **THEN** 사유 코드별 KR·US 값이 가로 스크롤 없이 읽힌다
