# a175 인지 부하 점검

기준: 한 화면에서 운영자가 안전 상태·사유·다음 읽기 경로를 찾기 위해 세 곳 이상을 왕복해야 하면 `높음`으로 분류함. 설명 접기는 값·사유·안전 상태를 감추지 않는 경우만 허용함.

| 화면 | 주 작업 | 관찰 | 판정 |
|---|---|---|---|
| 최적화 개요 | 상태와 변경 범위 파악 | 카드 그리드를 제거하고 actor/reason/digest만 남김 | 낮음 |
| 청산/보호 | preset 비교 후 preview 진입 | T1~T4를 열 기준으로 비교하고 기존 POST form은 각 열 아래 유지 | 보통 |
| 종목별 관리 | 전용 화면으로 이동 | 요약 1개와 링크 1개, owner 미연결 사유를 같은 문단에 표시 | 낮음 |
| 후보 필터 | KR·US dormant 기준 확인 | key별 값·미승인·미측정·누락·CAS는 펼치고 설명·preview 계약만 접음 | 보통 |
| 전략·실행 | lane·일정 화면으로 이동 | 안전 권한 요약과 링크 2개를 한 문단에 유지 | 낮음 |
| 성과·이력 | 성과 화면 이동과 감사 이력 확인 | 링크와 감사 표를 분리해 보존 | 보통 |
| strategy runtime | KR·US 독립 projection 판독 | 시장별 2열(모바일 1열), safety token은 접지 않음 | 보통 |
| 신호 | 그림자 기록과 후보/veto 수 분리 | 공통 설명 1회, 그림자 설명만 접음 | 낮음 |

`높음`은 0개임. 후보 필터의 높이 목표 초과는 `measurement-comparison.md`에 별도로 기록했으며, 이를 맞추려고 여백·줄 간격 또는 안전 정보를 줄이지 않음.
