# Function Logic Map: `_hidden_by_index_flags` (Python, a122 task 7.5.27, 새 함수)

`ast.after-7.5.27.json` 이 범위를 적는다.

## 답하는 질문

**"인덱스 플래그로 편집을 감춘 `*.go` 가 있는가."** 워킹트리 대상에서만 불린다(커밋 대상은 blob 끼리
견주므로 무관하다). 반환은 감춘 경로 목록이고 호출자가 이름 대고 거절한다 — **가장 뒤에서**.

## 갈래

| 갈래 | 무엇 | 왜 |
|---|---|---|
| `git ls-files -v -s -z` 의 rc ≠ 0 | 결함 | 못 물은 것을 "없다" 로 읽지 않는다 |
| 레코드 머리가 네 칸이 아님 | 결함 | 지어내지 않는다 |
| 태그가 `S`(skip-worktree)도 소문자(assume-unchanged)도 아님, 또는 일반 파일 모드가 아님 | 건너뛴다 | 플래그가 없으면 git 이 파일을 본다 |
| 파일이 디스크에 **없음** | 건너뛴다 | sparse-checkout 모양 — 감출 편집이 없다 |
| 플래그 붙은 파일이 없음 | 빈 목록 | 해시 프로세스를 안 띄운다 |
| `git <고정> hash-object --stdin-paths` 의 rc ≠ 0 · 답의 수가 다름 | 결함 | |
| 해시 ≠ 인덱스 blob | **감춘 편집** | 플래그만 있고 바뀌지 않았으면 정상이다 |

**플래그만으로 거절하지 않는 이유**는 sparse-checkout 이다 — 정상 도구가 `skip-worktree` 를 쓴다. 해시는
판정과 **같은 고정**으로 한다: 필터 드라이버는 끄되 줄끝 변환 같은 속성은 `git add` 와 같이 적용되므로,
바뀌지 않은 파일은 인덱스와 같은 해시가 나온다.

시험: 감춘 편집 둘(subTest) · 플래그만 있고 편집 없음 + 파일 없음(경계) · 커밋 대상(경계). 변이 `AF7~AF11`.
