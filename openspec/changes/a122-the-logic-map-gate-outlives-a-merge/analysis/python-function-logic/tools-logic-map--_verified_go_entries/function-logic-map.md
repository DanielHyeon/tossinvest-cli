# Function Logic Map: `_verified_go_entries` (Python, a122 task 7.5.34 — 새 함수)

`ast.after-7.5.34.json` — 분기 **18** · raise 5 · 반환 1.

## 답하는 질문

커밋마다 `*.go` 경로 → (모드, oid) 를 **검증한** 커밋과 트리에서만 읽는다. git 은 뿌리 트리 · 커밋은 파싱할 때 해시를
보지만 **하위 트리는 해시 없이 읽는다** — 하위 트리를 빈 트리로 위조하면 `ls-tree -r` 에서도 그 아래 파일이 조용히
사라진다(2.43 실측, 7.5.34 작업 중). 그래서 트리를 git 에게 걷게 하지 않는다.

## 믿는 것

`hints` 와 `ls-tree` 의 대답은 믿지 않는다 — 물을 목록일 뿐이다. 커밋 oid 는 `rev-parse <base>^{commit}` 의 답을 믿는다
(base 는 `base-commit.txt` 의 sha 이고, 그 이름이 무엇을 가리키는지가 곧 base 의 정의다).
