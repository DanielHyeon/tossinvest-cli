# Function Logic Map: `_snapshot_disagreement` (Python, a122 task 7.5.31 — 새 함수)

`ast.after-7.5.31.json` — 분기 **15** · raise 4 · 반환 0. `enumerate.py` 가 기계로 열거했다.

## 답하는 질문

게이트가 **스스로 해시한** 워킹트리 oid(스냅숏의 `placed`)와 base 트리의 oid 가 다른 경로를, git 의 diff 가 정말로
내용 변경으로 보여 주었는가. 두 diff 는 스냅숏 blob 을 **oid 로** 다시 찾으므로, 실제 저장소가 그 oid 에 다른
바이트를 담고 있으면(loose · pack) **둘이 함께** 속는다(7.5.25 적대 재리뷰 F2 · F3). 대조의 한쪽은 git 이 아니어야 한다.
