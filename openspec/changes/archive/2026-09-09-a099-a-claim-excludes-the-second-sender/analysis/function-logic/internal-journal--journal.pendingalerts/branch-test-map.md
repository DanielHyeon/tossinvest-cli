## ⚠ R21이 이 함수에서도 핀인 이유

`UndeliveredCount`의 branch test map과 같은 논거다. design D1의 안 A를 골랐다면
발송 중인 행이 `state='PENDING'`이 아니게 되어 **이 목록에서도 빠졌을 것이고**,
그러면 운영자는 밀린 것이 없다고 읽는다.

**발송자가 죽으면 그 행은 어느 읽기 경로에도 안 나타난 채 남는다** —
그것이 안 A를 버린 이유다.
