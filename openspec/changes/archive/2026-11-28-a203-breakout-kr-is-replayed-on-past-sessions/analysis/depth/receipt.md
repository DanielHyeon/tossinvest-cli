## 판정 (design §9 분기 규칙)

- 규칙 「요청한 날짜의 봉을 1개 이상 돌려주면 그 날짜까지 깊이 있음」: G1~G5 모두 요청 날짜 봉 3개 → **1분봉 깊이 ≥ 2024-11-27(약 730일)**.
- **G3 성공 → §6 주 표본 그대로(100 세션)**. G1 까지 성공해 깊이가 주 표본보다 훨씬 길다는 사실만 기록하고, 사전등록 표본 크기(100 세션)는
  바꾸지 않음. §6 깊이 분기 · 「40 세션 미만이면 중단」은 해당 없음.
- G7 이 과거 날짜(2026-06-10)의 달력을 줌 → 세션 개장 · 마감 시각 출처는 **달력**(일봉 날짜 + 기본 시각 대체 경로 불필요).
- G6: 일봉 200개가 2026-02-02 까지 닿음(§8 「200 봉 ≈ 9.5 개월」과 일치).
- 출처 대조: a182 「1분봉 730일」(영수증 미발견) — 730일 지점에 봉이 있음을 확인(상한은 안 잼). a128 「최소 9일」 — 하한을 크게 넘음.
- 한계: 한 종목만 잼(§9 한계 그대로). 730일 너머 · 다른 종목의 깊이는 미측정.

## 관찰

- 모든 1분봉 응답에 15:29 · 15:30 봉이 있음 — 15:20~15:30 단일가(동시호가) 구간의 봉. a204 재생기는 15:20~15:29 봉을 버림(Manager 메모).
- 1분봉 15개 중 `volume` 키가 있는 것은 G1 15:30 봉 1개뿐. `domain.Candle` 의 `json:"volume,omitempty"`(`internal/domain/models.go:381`)라
  키 없음 = 0 임. 이 응답은 단일가 구간만 담으므로 정규장 1분봉 거래량 유무는 이 영수증으로 판단할 수 없음. G6 일봉은 200개 모두 `volume` 키 있음.
