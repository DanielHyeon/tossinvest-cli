// a189: shapes.json 값 하나를 Go encoding/json 문자열 인코딩(HTML 이스케이프 포함)으로 만듦 — corpus 의 기존 표기와 같게.
package main

import (
	"encoding/json"
	"fmt"
	"io"
	"os"
)

func main() {
	b, err := io.ReadAll(os.Stdin)
	if err != nil {
		panic(err)
	}
	out, err := json.Marshal(string(b))
	if err != nil {
		panic(err)
	}
	fmt.Print(string(out))
}
