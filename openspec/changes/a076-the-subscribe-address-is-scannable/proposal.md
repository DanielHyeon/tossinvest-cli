# a076 · 구독 주소를 스캔한다

## 왜

a075는 알림을 버튼 하나로 켠다. 그리고 운영자에게 이런 주소를 준다.

```
https://ntfy.sh/tossos-mnzxcvbnmasdfghjklqwerty
```

기계 앞에 앉아 있으면 링크를 누르면 끝난다. **폰으로 받으려면 26자 난수를 손으로
쳐야 한다** — 그리고 폰이야말로 critical 알림이 도착해야 할 곳이다. 보호가 멈춘
포지션을 알려주는 알림이 기계 앞에 있을 때만 도착한다면 그것은 알림이 아니다.

a075가 없앤 마찰(설정 파일 손편집)을 절반만 없앤 셈이다. 남은 절반이 이것이다.

## 무엇을

카드에 **QR 코드**를 그린다. 폰 카메라로 찍으면 ntfy 앱이 그 주소를 연다.

QR 인코더를 이 저장소에 넣는다 — `internal/qr`, 순수 Go, 외부 의존 없음.
바이트 모드·EC 레벨 M·버전 1–10. 그 범위가 담는 것은 213바이트이고, 자체 호스팅
도메인을 포함한 어떤 ntfy 주소도 그 안에 들어간다.

렌더는 인라인 SVG이고, **`template.HTML`을 쓰지 않는다.** 템플릿이 정수 좌표를
`<rect>`로 반복 출력하므로 raw HTML 주입 지점이 새로 생기지 않는다.

## 무엇을 하지 않는가

- **주소를 바꾸지 않는다.** QR은 카드가 이미 표시하는 문자열을 그대로 인코딩한다.
- **새 라우트를 만들지 않는다.** SVG는 설정 페이지 본문 안에 있다 — 이미지 라우트를
  만들면 채널 주소가 URL 경로에 실리고, 그것이 a075가 리다이렉트에서 막은 것이다.
- **알림 설정·전송·outbox·entry gate를 건드리지 않는다.**
- **기존 함수를 하나도 편집하지 않는다.** 새 패키지, 새 파일, 그리고 템플릿 상수뿐이다.
