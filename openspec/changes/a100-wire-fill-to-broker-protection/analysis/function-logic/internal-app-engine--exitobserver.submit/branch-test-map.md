## 이 측정이 a100에 갖는 뜻

이 함수는 **손절 주문의 유일한 발행 지점**이다. 정상 경로(B2·B7·B8·B10)만 검증돼 있고,
발행을 막는 네 경로(B1·B3·B4·B5)는 전부 미실행이다.

a100은 여기에 **「상주 주문이 먼저 체결되어 이미 flat」이라는 새 상태 구별**을 넣는다.
새 조건을 B2 앞에 두면 그것은 **제출을 막을 수 있는 다섯 번째 경로**가 되고, 앞의 넷이
미검증인 상태에서 다섯 번째가 늘어난다.

⇒ **a100은 이 함수에 제출을 막는 새 조건을 넣지 않는다.** 「이미 flat」은 B2가 이미 잡는다
(수량 0 → `release`). a100이 바꾸는 것은 **그 결과의 이름**뿐이다 —
`ProposalRefused`(보호 실패)가 아니라 「상주 주문이 보호를 완료함」으로 기록한다.
분기 수는 늘지 않는다.

## a100의 RED 대상

- **수량 0 분기(L1243) — RED 필수.** 상주 주문 체결로 flat이 된 경우가 「보호 실패」와
  **구별되는 결과**로 기록되는지.
- **발행 차단 4경로(L1240·L1263·L1272·L1277) — RED 권장, 범위 판단 필요.** a100이 이 경로들에
  새 원인을 더하지는 않는다. 그러나 **손절 발행 실패 경로가 전부 미검증**이라는 사실 자체가
  기록돼야 한다 — tasks 6.5의 정리 change 후보.
- **in-doubt 분기(L1296) — 회귀 고정.** 상주 주문 mutation의 in-doubt도 같은 규칙(놓지
  않는다)을 따르는지.
- **심볼 경합(L1301)·detail 대체(L1306) — a100 범위 밖.**
