## 확인 항목

- 준비도는 절 단위 여섯 행이며, 상태가 `unknown`이면 seam 미배선 또는 읽기 실패 사유를 표시함. 0값을 통과로 해석하지 않음.
- 한도 비교표는 좁은 화면에서 `table-scroll` 안에 유지함. 가로 스크롤은 표 구조를 보존하기 위한 것이며, 별도 제어를 만들지 않음.
- 거래 정책은 기존 POST form·필드·hidden CSRF를 유지하고, 저장·주문·엔진 제어 클릭 수를 늘리지 않음.
- 데스크톱 `/settings/daily`는 2,445px·notice 3개, 모바일은 3,365px·notice 3개로 측정됨. 요구한 데스크톱 높이·상자 목표를 충족함.
