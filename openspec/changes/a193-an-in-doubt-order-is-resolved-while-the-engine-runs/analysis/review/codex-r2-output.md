**[P2] ‘15초 이내’는 HTTP 시한에서 도출되지 않는다 — 새 상한 주장 오류**

- **근거:** `design.md:146,298`; `review.md:68`; `internal/accountbudget/transport_linux.go:400–418`.
- **사실:** 응답 없는 경로에서도 transport는 요청 종료 뒤 `WithoutCancel` 기반 최대 2초의 `obs.Finish`를 거쳐 lease를 해제한다.

- **최소 제안:** 숫자 상한을 철회하고 HTTP 시한·후처리·lease 해제를 구분한다. 실제 지연값은 미측정으로 남긴다.

**[P2] 커밋 검사 뒤 취소 시 ‘park는 남는다’는 확정할 수 없다 — 사실 단정 과잉**
