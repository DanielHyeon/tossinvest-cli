> `not-applicable`이 아니라 **덮이지 않았다**로 적는다.

> **R 이 테스트의 구멍을 찾았다 — 코드가 아니라 테스트를.**
> 첫 판의 인증 테스트는 **목록 라우트만** 봤고, 승인 라우트에서 `alertControlAuth`
> 를 떼어낸 뮤테이션이 **네 테스트를 전부 통과했다.** 인증이 더 필요한 쪽은
> 반대다 — 목록은 읽고 승인은 **게이트를 푼다.** 두 라우트 × 세 토큰으로 넓혔고,
> 같은 뮤테이션이 `POST … = 200, want 401` 로 잡히는 것을 확인했다.
>
> **「토큰을 검사한다」를 라우트 하나로 재면 검사가 있는 라우트만 재는 것이다.**
