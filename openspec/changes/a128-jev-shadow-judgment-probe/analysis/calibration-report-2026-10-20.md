## 결론

1. **J1(60분 내 상승 판단)은 예측력 없음으로 기록한다.** p 구간과 실현 적중률의 관계가 평평하거나 약하게 거꾸로다
   (p<0.50 → 0.581, 0.50–0.55 → 0.547, 0.55–0.60 → 0.549). 같은 사이클 안에서 J1 순위와 60분 수익률 순위의 상관은
   평균 −0.000(132 사이클). design.md 「판단 설계」 규칙대로 **J1 은 배선 후보에서 제외**로 기록한다.
2. **J2 p≥0.9 는 판정 불가(보류)다 — 표본 0.** 주 표본 3,990 판단, 원장 전체 7,710 J2 판단 어디에도 p≥0.9 가 없다
   (최댓값 0.85). 더 아래 구간에서는 J2 가 **거꾸로** 움직인다 — p 가 높을수록 60분 수익률이 음수인 비율이 낮다
   (p<0.50 → 0.441, 0.70–0.75 → 0.240). 이 측정 창에서 J2 는 「60분 하락」의 대리 지표로 쓸 수 없다.
3. 측정은 **4 세션(KR 2 · US 2)·133 사이클**이고, 같은 종목이 10분마다 다시 판단되며 60분 창이 겹친다. 실효 표본은 행
   수보다 훨씬 작다. 모든 판정은 예비다.

2. 위 필터 정의대로 줄을 고른다(바이트 그대로).
3. `go run ./tools/a128-jev-shadow-probe report -ledger <사본>` → [도구 출력](calibration-report-2026-10-20-tool-output.txt)과 비교.
4. 보조 수치(Spearman·일별·bootstrap, seed 20261020, 2,000 회)는 저장소 밖 스크립트 산출물이며 원문은
   [보조 분석](calibration-report-2026-10-20-aux-analysis.txt)에 있다. state 필드: `change_pct_vs_reference`(당일 등락),
   `intraday.vs_window_vwap_pct`, `daily.return_{1d,5d,20d}_pct`; 결선·제외는 judgment 행 `screen`.
