## ADDED Requirements

### Requirement: 의미 판단은 측정 영수증 없이 발주 경로에 배선되지 않는다
외부 의미 판단 모델의 확률 p 에 대한 임계값은 측정 영수증 없이 발주 경로에 배선되어서는 안 된다 (MUST NOT).
영수증은 그 질문·그 시장의 shadow 원장에서 p 구간별 실현 적중률을 센 것이어야 한다 (SHALL).
손절·비상 청산 경로에는 측정 결과와 무관하게 의미 판단을 배선해서는 안 된다
(MUST NOT — 외부 호출 의존이 즉시성을 약화한다).

#### Scenario: 측정 없이 임계값을 발주 게이트로 올리려 한다
- **WHEN** shadow 원장 측정 영수증이 없는 질문의 p ≥ 0.9 조건을 매수 경로에 넣으려 한다
- **THEN** 그 배선 change 는 측정 영수증 부재로 거부된다

#### Scenario: 손절 경로에 판단을 끼우려 한다
- **WHEN** 의미 판단 호출을 손절·비상 청산 실행의 선행 조건으로 두려 한다
- **THEN** calibration 결과와 무관하게 거부된다

### Requirement: shadow 판단은 side effect 가 없고 계좌 데이터를 내보내지 않는다
shadow 프로브는 브로커에 읽기 요청만 보내야 하며 (SHALL), 어떤 주문 생성·정정·취소·토글
변경도 수행해서는 안 된다 (MUST NOT). 외부 판단 API 로 전송되는 state 는 공개 시장
데이터만이어야 하며 (SHALL), 계좌 식별자·보유·잔고·시크릿·세션 토큰을 포함해서는 안 된다
(MUST NOT).

#### Scenario: state 조립기에 계좌 필드가 들어온다
- **WHEN** state 조립 입력에 계좌 식별자 또는 보유 수량 필드가 섞인다
- **THEN** 조립기는 해당 필드를 전송 state 에 포함하지 않고, 시험이 이 차단을 고정한다

### Requirement: 원장 행은 판단의 모집단을 복원 가능하게 적는다
각 판단 행은 시각·시장·심볼·질문 원문 버전·state digest·p·기준가를 포함해야 한다 (SHALL).
라벨 행은 판단 행 참조와 실현 결과 또는 라벨 결손 사유를 포함해야 한다 (SHALL).
수집 결손(예: 뉴스 부재, rate limit 포기)은 행에 명시되어야 한다 (SHALL — 침묵한 생략 금지).

#### Scenario: 뉴스 소스가 없는 세션의 판단
- **WHEN** WTS 세션 부재로 뉴스 없이 판단이 이루어진다
- **THEN** 원장 행과 전송 state 양쪽에 뉴스 결손이 명시된다
