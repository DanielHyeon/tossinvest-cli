# a169 U2 합집합 해석 정정

정본 `design.md:98-110,134-142,164-176`과 proposal Q3를 손읽기했다. 코드·시험·운영 없음.

각 랭킹의 각 원본 항목에 공통 필터를 독립 적용한 뒤 통과 심볼 집합의 합집합을 취하고 심볼을 중복 제거하는 ANY-pass는 `design:136-137`에 직접 부합한다. 앞선 연구의 '양쪽 필터 결과가 다르면 전체 오류 권고'는 이 포함 규칙에 관해 과도했으므로 철회한다. volume/amount 원본과 각 필터 판정·사유를 함께 보존하면 왜 한쪽으로 포함됐는지 설명할 수 있다.

분자 V는 `design:141-142`의 명시대로 해당 심볼이 원본 volume 랭킹에 있으면 그 값, 없으면 amount 값이다. volume 원본이 필터에 실패했더라도 amount가 통과해 합집합에 든 심볼에는 문언상 volume 값이 우선한다. 값이 invalid면 별도 numerator_invalid다. 동률은 `:168-169` 원본 volume rank→amount rank→symbol 순서다. 이 해석을 금지하는 별도 spec 문구는 확인하지 못했다. rank의 미존재·동률·중복은 승인된 순수 입력 지원 제한과 구분한다.

남은 모호함은 후보 선정이 아니라 `design:175`의 **단일 `last_price` 원장 칸**이다. 두 원본의 가격이 다르거나 한쪽만 필터를 통과할 때 어느 가격을 기록할지 정본이 특정하지 않는다. 순수 결과는 두 원본·두 사유를 보존하고 단일 canonical price를 투영하지 않아도 포함/점수/tie 계산 가능하다. 실제 ledger 결합 전에는 양쪽 값을 보존하도록 schema를 정정하거나 단일 칸의 출처를 정해야 한다. 이는 현재 순수 합집합 로트의 포함 판단 blocker가 아니며 원장 구현을 무근거로 완료할 수 없다는 후속 blocker다.
