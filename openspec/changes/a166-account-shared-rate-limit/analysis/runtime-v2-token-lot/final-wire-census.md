## 미완·발견

1. 현재 main ec8은 runtime v1/OpenContext여서 required의 새 관측 store binding은 미게시 상태다. 21b9 후보는 독립 검증 및 최신 main 통합 전이며, 양쪽을 합친 runtime 완료를 선언할 수 없다.
2. 현재 후보의 비test source에서 WithObservation/ObservationCollector의 엔진 호출은 없고 WithTokenObservation만 있다. 따라서 execgw/retry.go:335–353의 Retrier Query가 poll scope·공유 hint·collector를 소비하거나 429 후 freshness/retry를 막는 것은 후속 작업이다. design:73의 같은 RequiredQuery 보호·일반 read 공유도 아직 runtime 입증이 아니다. 이 항목은 기존 승인 scope에서 남긴 completion blocker이지 v2/token 로트의 별도 구현 결함이라고 판정하지 않는다.
3. app.New의 nil BudgetProvider, engine.NewOrderPath의 nil BudgetFactory, public low-level Budget/Open/NewWithAccountBudget/HTTPReplay는 legacy/OFF 또는 명시 저수준 API로 남아 있다. source내 CLI 일반 진입의 값 흐름은 위와 같으나 임의 외부 caller·다른 바이너리·runtime namespace 전 참가자의 강제성은 증명하지 않았다. 이를 제거했다고 주장하지 않는다.
4. candidate/soak 164db는 ec8에 게시됐으나 v2 후보와 아직 물리적으로 통합되지 않았다. 통합 시 공유 root fixture와 최신 변경 census·선택 시험을 다시 확인해야 한다.

실제 배포 manifest의 동등 inode·namespace, 브로커, 실계좌, 운영, 전체 test/gate와 전체 a166 완료는 미검증이다.
