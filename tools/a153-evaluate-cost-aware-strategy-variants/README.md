# Offline independent filter comparison

Run `python3 tools/a153-evaluate-cost-aware-strategy-variants/analysis.py tools/a153-evaluate-cost-aware-strategy-variants/testdata/kr-us-synthetic.json --output NEW.json`. Output is created exclusively; existing files and symlink paths are refused. Use `-` to read JSON from stdin. Run tests with `python3 -m unittest discover -s tools/a153-evaluate-cost-aware-strategy-variants -p 'test_*.py'`. The aggregate repository gate does not discover this suite.

The complete synthetic manifest is in `testdata/kr-us-synthetic.json`. Its top-level keys are exactly `version: "a153-v1"`, `mode: "independent_filters"`, `synthetic` (boolean) and `candidates` (up to 1000). Each candidate has the exact schema described in the [a151 README](../a151-compare-stop-policies-offline/README.md): identity, market/currency, signal and session, tick, cost and risk-limit snapshots, entry/exit slippage ticks, and supplied one-minute and five-minute OHLCV bars. Maximum input is 16 MiB. Strings are limited to 256 characters and a151 numeric fields retain its 64-character unsigned plain-decimal restrictions. Timestamps must be RFC3339 whole seconds or 1–6 fractional digits, with `Z` or a whole-minute offset in the valid range.

The original universe is limited to a151-compatible candidates, including its 15 five-minute-bar ATR warmup and valid geometry and quantity for all three stop arms, although only the fixed arm is scored. Candle means signal close greater than open; volume means signal volume greater than the immediately preceding five-minute volume; MFI means a147 MFI14 three-minute delta greater than 1e-9 from 18 available consecutive one-minute bars. Equal values are false; unavailable/late/undefined features are unknown. Each relevant five-minute bar requires all five constituent one-minute bars closed and received by confirmation and matching its OHLCV aggregate. Filters are independent and observations after confirmation cannot establish a feature.

Each candidate includes base and doubled-slippage executions from unchanged a151; primary scoring uses only fixed stop-first. Target-first is an ambiguity diagnostic. Results are simulated PnL and R with caller-supplied, unverified data, not actual account results. A known filter rejection has zero simulated contribution, not a zero-risk trade. Unknown or unresolved outcomes are never zero. Every candidate in a market/date must have all filters known and fixed stop-first closed under both scenarios for that entire session to join the common cohort. The report includes all candidate IDs, states and session exclusions; means first weight candidates within session, then weight sessions equally. Conditional executed-trade mean and count are separate. KR/KRW and US/USD are never pooled. Bootstrap resamples paired session differences 2000 times with seed 153 and uses linear interpolation for 2.5% and 97.5% percentiles; under 20 sessions is insufficient and any size remains exploratory.

Input and reused source SHA-256 hashes bind the bytes, but do not authenticate provenance or an untouched holdout. Profitability is always inconclusive and production authorization false. VP, SI, MA20, EMA exits, partial exits, portfolio MDD, MAE/MFE, exposure/turnover, regime inference, authenticated holdout, FX and policy promotion are deferred. No data collection, orders, configuration changes or live integration occur.
