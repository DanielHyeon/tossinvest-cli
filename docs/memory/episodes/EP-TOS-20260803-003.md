## Context

거래 이력에서 미국 ticker는 읽을 수 있었지만 한국 종목은 여섯 자리 코드만 보여
사용자가 어떤 종목인지 빠르게 알기 어려웠다. journal에는 성과 근거와 symbol은 있지만
현재 종목명은 저장하지 않는다.

## Observation

종목명은 동결 성과 근거가 아니라 현재 설명 metadata이므로 journal projection을 바꾸거나
체결에서 재계산하지 않고 request-local로만 붙여야 한다. `(market, symbol)`을 키로 삼아
교차 시장 오염을 막고, 이름이 없거나 API가 실패하면 symbol과 모든 동결 행을 그대로
보여 주는 것이 안전하다.

선택적 metadata가 공식 API rate budget을 쓰므로 process-local mutex만으로는 별도
console/verify 프로세스의 시작 경쟁을 막지 못한다. 실행 배타 flock을 먼저 얻고 profile
intent marker를 필수 게시한 뒤 kernel rate-budget lease를 잡는 순서가 필요하다. Abort는
active verifier와 동시에 marker를 소유하지 않고, 배타 admission 뒤 record를 다시 읽어
추가되거나 이미 종결된 대상을 정확히 반영해야 한다.

## Evidence

KR/US trip과 exit-event가 `symbol · name`을 동일하게 렌더하고, 누락·부분 응답·API 실패·
control/bidi/길이 초과·HTML payload에서 symbol과 동결 값이 보존됨을 테스트했다. 24시간
bounded cache, 1분 실패/부분 backoff, single-flight, 10초 total timeout, 200-symbol chunk와
400-ref 제한을 검증했다. 별도 프로세스 lease, verification priority, marker 게시 실패,
active-verifier abort 거부, post-admission target 추가·종결을 일반/race 테스트로 고정했다.
보안·테스트·유지보수 독립 검토는 최종 NO FINDINGS였고 전체 Go test, vet, 58개 strict
OpenSpec, SDD와 full gate가 통과했다. 배포된 `/history`에서 KR `272210 · 한화시스템`,
US `IONQ · 아이온큐` 표시를 확인했다.

## What to reuse

원장 근거에 없는 현재 설명값은 authoritative field로 승격하지 말고 bounded fail-soft
read-model enrichment로 붙인다. 선택적 외부 조회가 supervised live 작업과 같은 제한을
공유하면 profile-scoped kernel lease와 strict intent publication을 사용하고, cleanup은
exclusive admission 뒤 대상을 다시 projection한다.

## What not to infer

현재 종목명은 과거 시점의 명칭이나 동결 성과 근거가 아니다. 이 경로는 journal schema,
손익 계산, 포지션 정책, 엔진 토글, automation gate, 계좌 선택 또는 LIVE 주문 승인을
추가하지 않는다. Metadata 실패가 거래 이력 행을 숨겨도 된다는 뜻도 아니다.
